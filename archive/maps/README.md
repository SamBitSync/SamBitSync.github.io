# Retired standalone maps

These files are outside Astro's published collections and generate no pages.

The source paths are preserved below `archive/maps/src/`:

- `content/maps/dynamics-of-belief.mdx` and `components/maps/BeliefDynamicsMap.astro`: the attractor experiment, removed from the public Maps catalogue. Its text describes a mechanical analogy rather than an established model of belief revision.
- `content/maps/theories-of-cognition-moc.mdx`: the former standalone overview. Its useful introduction, interactive diagram and note references now live in `src/content/maps/research-programmes.mdx`. The diagram component remains active in `src/components/maps/TheoriesOfCognitionMap.astro`.

The former theories URL redirects to the merged map. The belief URL is no longer published. Restoring an experiment should be a deliberate editorial decision; these archived files are not drafts that publish automatically.
