# The chain: theory → mechanism → observable

What precision do you actually need?

Let's formalize the chain:
1.  **Theory**: "Subject predicts X"
2.  **Mechanism**: "Oculomotor system targets location of X"
3.  **Observable**: "Eye tracker reports coordinates (x,y)"

The error propagates. If the target is large, the tolerance for error in step 3 is high.
We can define the required precision $P$ as a function of target separation $S$ and target size $T$.
