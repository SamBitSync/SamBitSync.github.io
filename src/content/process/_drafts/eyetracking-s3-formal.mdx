# Event loops, buffers, and the synchronization problem

The experiment is a loop running at 60Hz (screen refresh).
The eye tracker is a loop running at X Hz.
The audio is a separate thread.

**The Problem**: How do we align these timelines?
We need a common clock. PsychoPy uses `core.Clock`.
We must send triggers (messages) to the eye tracker data stream at precise screen flips to mark events.

`tracker.sendMessage('TRIAL_START')` must happen exactly when `win.flip()` happens.
