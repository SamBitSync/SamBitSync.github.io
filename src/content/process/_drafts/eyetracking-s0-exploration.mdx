# I know fixations = processing, but what actually gets processed?

We often assume that if the eye is on an object, the brain is processing that object. But is that always true?

In the Visual World Paradigm, we see anticipatory looks. But are these looks reflecting:
1.  **Lexical access**: "I heard 'can' so I look at the candle"
2.  **Prediction**: "I expect 'candle' so I look"
3.  **Integration**: "I'm building a scene model"

This entry explores the ambiguity of "processing" in eye-movement data.
