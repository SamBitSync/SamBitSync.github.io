# Drift detection and when to recalibrate mid-experiment

Drift is inevitable. The head moves, the eye dries, the system heats up.

**Problem**: If we recalibrate too often, we annoy the participant. If too rarely, data is garbage.

**Solution**:
- Drift check before every trial (single point).
- If error > threshold (e.g., 2°), trigger full recalibration.
- Monitor drift trends over time.
